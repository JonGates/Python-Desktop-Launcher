# 简化项目绑定与动作编辑

状态：设计待复核，尚未实现。

## 用户目标

一个项目、一个 Launcher.exe、多个启动动作，每个动作直接管理自己的参数。首次接入只绑定项目和 Python 环境；普通用户不必理解动作 ID、argv 或参数引用。配置时可立即看到表单，保存成功后直接查看该动作。保持紧凑的原生 WPF 界面及独立设置页。

## 1. 首次接入与空状态

- 移除入口文件控件及脚本自动预选；保留项目目录、环境选择和「绑定并进入」。
- 创建配置时 actions 为显式空列表，不自动创建业务动作或检查解释器动作。环境检查保留在环境管理页。
- 放宽配置校验为 0–100 个动作，仍拒绝 actions: null。主窗口、运行页、设置页和 CLI 均安全处理空列表，不调用 First() 假设动作存在。
- 空运行页只显示「尚未添加启动动作」和「添加启动动作」。无法执行不存在的动作；环境管理和终端仍可用。
- 删除最后一个动作后进入同样的空状态。已有配置优先读取且首次绑定不覆盖。
- 新版读取现有 schema v1 配置；新版生成的空动作配置不保证旧 EXE 可读取，升级说明明确这一边界。

## 2. 单一动作编辑器

设置保留基本信息、启动动作、高级 YAML。启动动作内统一编辑名称、执行目标、参数，不再要求在两个标签之间手工绑定。

- 名称支持中文；新动作自动生成唯一、合法且稳定的 ID，改显示名称不改 ID。已有 ID 原样保留，高级编辑仍可查看。
- 常规启动方式为 Python 脚本、Python 模块、其他程序。脚本/程序可浏览，模块填写模块名，Python 自动使用绑定环境。
- 现有任意 argv 无法无损映射到常规方式时，保留原始参数数组并显示高级命令模式；不静默简化命令。
- 常规参数行显示名称、命令参数、类型、默认值；新参数自动生成内部 name 并绑定当前动作。开关默认使用 flag 语义。
- 更多设置保留必填、说明、选项、范围、位置参数、环境变量、secret、条件显示等现有能力。复杂现有字段未经编辑不丢失。
- 参数新增、移除、排序均针对当前动作；移除引用不自动删除被其他动作使用的定义。

## 3. 兼容共享参数

继续使用现有全局 definitions + 动作引用，不引入新 YAML 字段。新动作默认显式 parameters: []。

已有 null（全部参数）、[]（无参数）、显式列表保持各自语义，不能在打开或无关保存时自动互换。对「全部参数」动作修改成员时，明确提示并确认转为显式列表；取消则不修改。

已有共享参数显示共享标记。编辑共享定义前提供「修改所有引用」或「复制为当前动作独立参数」选择；复制时生成新 name，并保留其他动作及条件引用的原语义。不得静默修改其他动作。

## 4. 实时预览与保存

- 编辑器显示标注为「草稿预览」的实际参数表单及脱敏命令预览；输入更新后刷新，不启动项目代码、不安装依赖。
- 草稿临时无效时显示对应字段错误，不把旧的有效预览伪装成最新结果。环境缺失不妨碍编辑表单，命令预览明确提示环境未就绪。
- 预览测试值独立于正式运行值和预设；敏感值不持久化、不明文出现在命令预览。
- 「保存并查看」先提交编辑器值、校验、检查磁盘冲突与运行状态，然后通过既有安全保存机制写入并备份。
- 保存失败留在设置页，保留草稿，聚焦问题字段；不改变运行配置，不跳转。
- 成功后等待视图配置刷新完成，再选中刚编辑的稳定动作 ID 并跳到运行页，立即显示已保存参数。无动作则显示空状态。
- 任务或终端仍运行时继续阻止配置应用，不绕过原保护。

## 5. 紧凑布局

编辑与预览在宽窗口并排；小窗口可滚动或切换预览，保存按钮始终可达。继续使用现有深浅主题资源。不含参数的运行页隐藏大块参数卡片和无用预设控件，日志获得剩余空间。

## 6. 实现边界与验证

Core 负责动作草稿到现有模型的安全映射、唯一标识、参数引用与校验；Desktop 负责编辑、预览和保存后导航。避免继续把全部逻辑堆入 SettingsView，拆分动作编辑控件/草稿服务。Core 不引用 WPF。

先新增失败测试再实现：零动作读写及打开/删除、中文名称自动 ID、脚本/模块/高级 argv 往返、不同动作参数隔离、共享定义确认、null/[] 语义、默认值 0/false、敏感值保护、无效草稿/保存失败不跳转、保存成功准确定位新动作。

运行完整 Core 与 Windows 可执行规格、Test-Windows.ps1、Python Demo 测试和静态检查。增加深浅主题最小窗口原生截图、实时预览与保存导航工作流检查。更新 Test-Portable.ps1 验证单 EXE 首次绑定无入口及零动作重开。通过后重新发布 EXE，更新报告与校验值；未执行的 DPI/IME 人工验收明确保留。

## 不包含

本轮不实现命令文本自动解析、业务脚本参数自动发现、多动作并行、自动执行预览、修改业务源码、安装业务依赖或改变单项目架构。
