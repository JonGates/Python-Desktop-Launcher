# Python Desktop Launcher v1.0.0

## 简体中文

一个 Python 项目，一个原生桌面启动器，多个启动动作。

- 将 Launcher.exe 复制到项目目录，已有 launcher.yaml 直接使用；没有配置时绑定已有环境，无需先填入口文件。
- 启动动作采用左侧列表、右侧配置，每个动作独立管理参数，新增/编辑使用弹窗。
- 简体中文 / English 即时切换并记住选择，保留未保存输入、运行任务与持续终端会话。
- 错误改为不占布局空间的悬浮通知，支持关闭和完整详情；关闭提示不会绕过校验。
- 双语快速使用 README，实际 WPF 截图，紧凑布局和深浅主题。

**下载：** 64 位 Windows 推荐 win-x64；32 位 Windows 使用 win-x86。推荐下载 ZIP，解压后复制 Launcher.exe，并在分发时保留许可证。单独 EXE 与 ZIP 中的程序相同。

**验证：** Core 84 项；x64/x86 分别完成 4 项 Windows 原生测试、37 项 WPF 检查（58 张图）和 6 项便携测试；Python 示例 13 项通过。x86 在 x64 Windows 的 WOW64 下验证。

**边界：** 程序未签名；人工 DPI、IME、完整业务流程、无 .NET 干净机器与独立 32 位 Windows 尚未验收。项目仍需要自己的 Python 环境；启动器不是沙箱，目前同时运行一个 GUI 任务。停止不是暂停。

## English

One Python project. One native desktop launcher. Multiple launch actions.

- Copy Launcher.exe into your project; reuse launcher.yaml or bind an existing environment without selecting an entry file first.
- Split action list/configuration layout, action-specific parameters and add/edit dialogs.
- Live Chinese/English switching with saved preferences; drafts, running jobs and persistent terminal sessions remain intact.
- Overlay error notifications with full details and dismissal, without shifting layout or bypassing validation.
- Bilingual quickstarts with actual WPF screenshots, compact layouts and dark/light themes.

**Downloads:** choose win-x64 for 64-bit Windows (recommended), win-x86 for 32-bit Windows. Prefer the ZIP and retain its licenses when redistributing. Standalone EXEs match the binaries inside the ZIPs.

**Verified:** 84 Core specs; each architecture passed 4 Windows native tests, 37 WPF checks (58 images) and 6 portable checks; 13 Python demo tests passed. x86 was tested under WOW64 on x64 Windows.

**Limitations:** unsigned binaries. Manual DPI/IME, full business workflows, clean machines without .NET and independent 32-bit Windows acceptance remain outstanding. Your project still needs Python. This is not a sandbox; currently one GUI job runs at a time. Stop terminates rather than pauses.

SHA256SUMS.txt contains checksums of the release assets. See README.md / README.zh-CN.md for quick start and docs/TESTING.md for verification scope.
